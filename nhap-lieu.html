Nhập liệu nhanh

Điền thông tin → sao chép dòng JSON → dán vào data.json trên GitHub. ← Về trang thống kê

1. Khoản thu / chi

Đã sao chép ✓
Có thể tạo nhiều dòng liên tiếp — mỗi lần bấm sẽ cộng dồn vào ô kết quả bên dưới.

2. Kết quả — dán vào data.json

Chưa có dòng nào.

3. Cách dán lên GitHub

  1. Mở repo → bấm vào file data.json.
  2. Bấm biểu tượng bút chì ✏️ ở góc phải để chỉnh sửa.
  3. Tìm mục "expenses": [ (khoản chi) hoặc "incomes": [ (khoản thu).
  4. Kéo xuống dòng cuối cùng của danh sách, thêm dấu phẩy , sau dấu } rồi dán nội dung vừa sao chép.
  5. Sửa luôn dòng "updated": "…" ở đầu file thành ngày hôm nay.
  6. Bấm Commit changes. Chờ khoảng 1 phút rồi tải lại trang thống kê.
